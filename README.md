# 雨落成诗 (Rain of Words) - 纯前端 Canvas 动效

复刻小红书创意编程作品《雨落成诗》的纯前端单文件版本。零外部依赖，使用纯原生 HTML5 Canvas + Web Audio API 实现。

---

## 核心动效与算法机制

1. **屋檐几何与连续碰撞曲线**
   - 将古典飞檐（反宇向阳、飞檐起翘）抽象为三次缓动样条曲线 $y = f(x)$。
   - 粒子下落时通过 $O(1)$ 局部区间二分/线性插值精准获取瓦面高度与切线斜率 $k = f'(x)$。

2. **双层粒子与碰撞分流**
   - **细雨丝 & 随机乱字池**：
     - 下落带有倾角、正弦水平漂移（$x = x_0 + A \sin(\omega t)$）与微幅自旋。
     - 撞击瓦面（$y \ge f(x)$）时触发**水花飞溅**（Splash 粒子沿法线随机散射）并湮灭。
   - **诗句文字状态机**：
     - `FALLING`（随雨滴下落） $\to$ `SLIDING`（触檐吸附，受重力切向分力加速度 $a = g \sin\theta$ 顺瓦面加速滑向檐角） $\to$ `DRIFTING`（离檐飞向右侧留白区域，自然错落分布，缓慢端正）。

3. **视觉美学细节**
   - **老照片黑白质感**：宣纸暖灰与阴翳雨雾背景、静默黑灰屋檐剪影与瓦垄纹理。
   - **落檐不强行排齐**：每个文字带独立的随机偏移量与倾角，保留自然动态，避免生硬对齐。
   - **右侧极简留白**：雨丝与乱字聚集在左半侧屋檐上方，右侧大面积留白，仅供成诗文字优雅流过。
   - **15 秒循环时间码**：内置 15s 电影感循环 HUD，支持实时重播与诗句切换。
   - **无感物理音效**：使用 Web Audio API 原生合成水滴落瓦轻微闷响（默认静音，点击右上角开启）。

---

## 使用方法

双击直接在任意现代浏览器（Chrome / Safari / Edge）中打开 `index.html`，或在当前目录启动本地服务器：

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：使用 Python 本地服务
python3 -m http.server 8080
```
